# Blood Cell Classification using CNN 🩸🔬

A Deep Learning project that classifies microscopic blood cell images into different cell types using a Convolutional Neural Network (CNN) built from scratch.

## 📌 Overview
Automated classification of blood cells plays a crucial role in medical diagnostics and hematology analysis. This project implements a custom CNN architecture in Python to process microscopic blood cell imagery, perform feature extraction, and classify blood cell types accurately.

## 🚀 Key Features
- **Custom CNN Architecture:** Built from scratch without relying solely on pre-trained models.
- **Image Preprocessing:** Scaling, normalization, and data preparation for microscopic imagery.
- **Performance Evaluation:** Training/validation loss & accuracy tracking with visualization plots.
- **Jupyter Notebook Workflow:** Clear step-by-step code execution and model training logs.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Deep Learning Framework:** TensorFlow / Keras
- **Data Manipulation:** NumPy, Pandas
- **Visualization:** Matplotlib, Seaborn
- **Development Environment:** Jupyter Notebook (`Blood_Cell_CNN_From_Scratch.ipynb`)
